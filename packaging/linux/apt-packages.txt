# Ubuntu 24.04 renamed this libasound2t64 (the time_t transition) and
# the old name has no candidate there; Debian bookworm, where the
# AppImage is built, still has the old one. Either satisfies — which
# is why every consumer installs this list with `apt-get satisfy`,
# one line per dependency string, rather than `install` (the release
# workflow found the rename, 2026-09-01).
libasound2t64 | libasound2
libfontconfig1

# QtNetwork probes GSSAPI during PyInstaller's Qt hook, and without this
# the *build* fails — not the application — with
